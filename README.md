## Reference Repositories

A `reference/` directory is included to house external repositories used for research and development. Run the provided setup script to clone them locally:

```bash
./setup.sh
```

This will clone the following repositories into `reference/`:

- [visa/visa-vulnerability-agentic-harness](https://github.com/visa/visa-vulnerability-agentic-harness)
- [langchain-ai/open-swe](https://github.com/langchain-ai/open-swe)
- [langchain-ai/deepagents](https://github.com/langchain-ai/deepagents)
- [karpathy/autoresearch](https://github.com/karpathy/autoresearch)
- [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)
- [aws-samples/bedrock-engineer](https://github.com/aws-samples/bedrock-engineer)
- [openai/codex](https://github.com/openai/codex)
- [aaif-goose/goose](https://github.com/aaif-goose/goose)

The cloned directories are listed in `reference/.gitignore` and are not tracked by this repository.
