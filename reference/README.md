# Reference Repositories

This directory contains clones of reference repositories used for research and development.

Run `../setup.sh` from this directory (or `./setup.sh` from the repo root) to clone all repositories.

## Repositories

| Repository | Description |
|---|---|
| [visa/visa-vulnerability-agentic-harness](https://github.com/visa/visa-vulnerability-agentic-harness) | Agentic harness for vulnerability research |
| [langchain-ai/open-swe](https://github.com/langchain-ai/open-swe) | Open Software Engineering agent by LangChain |
| [langchain-ai/deepagents](https://github.com/langchain-ai/deepagents) | Deep agents framework by LangChain |
| [karpathy/autoresearch](https://github.com/karpathy/autoresearch) | Automated research tooling by Andrej Karpathy |
| [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) | Hermes agent by NousResearch |
| [aws-samples/bedrock-engineer](https://github.com/aws-samples/bedrock-engineer) | AWS Bedrock engineer samples |
| [openai/codex](https://github.com/openai/codex) | OpenAI Codex |
| [aaif-goose/goose](https://github.com/aaif-goose/goose) | Goose agent |
